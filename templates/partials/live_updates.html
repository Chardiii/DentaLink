{# Near-real-time updates without full page reloads. Every 10 seconds (and whenever the tab becomes visible again) the page asks /api/live for a small fingerprint of the data it shows. When the fingerprint changes, the page fetches a fresh copy of itself in the background and swaps only its live sections. Open dialogs, typed text, the current tab, and scroll position are left alone: if the user is busy, the swap waits until they're done. Each page declares its live sections before including this partial: window.LIVE_REGIONS = ['.sidebar-nav', '#kanban-pipeline', ...]; and may define hooks to keep page state across a swap: window.liveHooks = { before() { return state; }, after(state) { ... } }; Pages can also listen for the 'live:updated' event to re-run their own setup. #}
