Create a backup

The ZIP includes DentaLink application database records, files in the dental-case-files storage bucket, and non-secret configuration values. Your browser downloads the archive; choose the Downloads folder if prompted.

This is manual only. It does not run automatically at noon.

Restore app data

Select a DentaLink backup ZIP. Restore merges records into the existing Supabase schema and overwrites matching records; it does not delete records that are absent from the archive.

Backups may contain sensitive dental and patient data. The ZIP is not encrypted, so store it only on a trusted, protected device. Database schema, Supabase Auth accounts, and secret credentials are not included. Keep a separate full Supabase backup for disaster recovery.
